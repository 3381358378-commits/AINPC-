## 2. 模块说明

### Frontend_MiniProgram

微信原生小程序前端。`map-explore` 负责地图、景点热区、扫码/手动打卡和导览音频；`chat` 负责六个景点的剧情状态机、文本/图片大模型请求、答题评分、奖励弹窗、TTS 队列和打字机渲染。WXML 及 WXSS 中的 `/images/...` 是以小程序代码包根目录为基准的资源路径，因此前端整体位于 `Frontend_MiniProgram` 后不需要改成 `../images/...`。

### Backend_Service

`server.py` 暴露 `/tts`、`/tts-stream` 和 `/health`。两个 TTS 路由共用同一套完整 MP3 生成逻辑，按“进程内 LRU -> 磁盘 MD5 -> 云端 CosyVoice”顺序处理，并通过 `Content-Length` 返回完整音频，避免微信端拼包异常。磁盘目录使用 `os.path.dirname(__file__)` 定位，因此从任意工作目录启动都写入 `Backend_Service/tts_cache`。

### Test_Scripts

性能脚本通过 `PROJECT_ROOT` 定位后端缓存目录，通过 `REPORT_PATH` 定位报告文件，不依赖当前 PowerShell 的工作目录。在线测试默认请求 `http://127.0.0.1:5006`；手机真机测试时，应将小程序中的地址改为运行服务电脑的局域网 IPv4 地址。

## 3. 路径依赖审查结论

| 项目 | 结论与处理 |
| --- | --- |
| 前端 API | 文本/视觉大模型请求使用云端 HTTPS 地址，与目录移动无关；TTS 使用本机 `127.0.0.1:5006`。已将 `map-explore.js` 原来的 5001 统一为 5006。 |
| 静态资源 | WXML/WXSS 使用 `/images/...`，属于小程序包根路径，保持不变；图片必须位于 `Frontend_MiniProgram/images/`。 |
| 后端缓存 | `CACHE_DIR = os.path.join(os.path.dirname(__file__), "tts_cache")`，以 `server.py` 所在目录为基准，移动后仍然正确。 |
| 测试缓存 | 测试脚本统一使用 `PROJECT_ROOT/Backend_Service/tts_cache`，不再错误读取 `Test_Scripts/tts_cache`。 |
| 测试报告 | 统一写入 `Test_Scripts/performance_test_report.txt`，从根目录或脚本目录执行均一致。 |

## 4. 模型与数据说明

### 4.1 知识库文档

- **数据名称**：`佗城龙川方志与赵佗史料汇编.docx`。
- **来源**：项目组整理的佗城地方志、赵佗相关历史材料汇编。正式参赛时建议在文档首页补充具体书名、作者/编者、出版信息、采集日期和页码，便于评审核验。
- **用途**：作为 `chat.js` 中 `KNOWLEDGE_BASE` 与系统提示词的事实约束，为赵佗生平、南越国治理、越王井、百岁街、越王庙、考棚、苏堤、正相塔等内容提供回答依据，并限制模型不杜撰。
- **格式**：原始资料为 DOCX；运行时主要内容整理为 UTF-8 JavaScript 模板字符串，不作为可执行模型权重。

### 4.2 路线与剧情数据

- **数据名称**：`旅游路线图及触发情境.docx`。
- **来源**：项目组根据佗城游览路线和比赛交互方案整理。
- **用途**：定义六个景点顺序、触发台词、答题节点、越王令奖励、最终结局和地图交互设计；实际运行逻辑固化在前端状态机常量与回调中。
- **格式**：原始资料为 DOCX；程序侧使用 JavaScript 对象、数组和字符串常量。

### 4.3 大模型调用格式

文本对话使用 DashScope OpenAI 兼容接口，核心请求为：

```json
{
  "model": "qwen-plus",
  "messages": [
    {"role": "system", "content": "赵佗角色设定与项目知识库"},
    {"role": "user", "content": "游客输入"}
  ],
  "temperature": 0.6,
  "top_p": 0.85,
  "stream": false
}
```

越王井看图使用 `qwen-vl-max`，用户图片以 `data:image/jpeg;base64,...` 放入 OpenAI 兼容消息的 `image_url` 内容项。API Key 属于运行配置，不属于模型数据；参赛提交前不得提交真实密钥，应使用环境变量或脱敏占位符，并及时轮换已经暴露过的密钥。

### 4.4 TTS 模型与音频格式

后端调用阿里云 DashScope CosyVoice：

- **模型**：`cosyvoice-v3-flash`。
- **音色**：`longsanshu_v3`。
- **输入**：JSON `{ "model": "...", "input": { "text": "..." }, "parameters": { "voice": "...", "format": "mp3", "sample_rate": 24000 } }`。
- **输出**：云端返回音频 URL，后端下载并校验后以 `audio/mpeg` 完整字节响应；本地缓存文件为 MD5 文件名加 `.mp3` 后缀。
- **用途**：将 AI 或剧情固定台词转换为语音，由小程序 `wx.downloadFile` 下载并交给 `wx.createInnerAudioContext` 播放；音频进度同步驱动打字机显示。

## 5. 运行与提交注意事项

1. 在 `Backend_Service` 目录启动：`python server.py`，服务端口为 `5006`。
2. 微信开发者工具导入 `Frontend_MiniProgram`，模拟器可使用 `127.0.0.1`；真机需改为电脑局域网地址，并确保网络可访问。
3. 提交前删除缓存、字节码、开发工具目录和调试备份；保留源代码、必要配置、说明文档和脱敏后的测试报告。
4. 云端 API Key 不应写入版本库或提交包。当前代码中的密钥字段应在参赛前统一检查并轮换。
